# Hi, I'm Mohammed Sabry

**Front-End Developer** based in Alexandria, Egypt.

I build fast, responsive, accessible websites, including bilingual Arabic (RTL) and English (LTR) interfaces with seamless language switching. Professionally I work with React.js and Next.js; in my own projects I also use Bootstrap 5, vanilla JavaScript and Three.js.

## What I care about

- Clean, reusable components and a scalable folder structure
- Performance: code splitting, lazy loading, fewer re-renders
- Accessibility (semantic HTML, ARIA, keyboard navigation) and SEO
- Arabic RTL layouts that feel native, not mirrored by accident
